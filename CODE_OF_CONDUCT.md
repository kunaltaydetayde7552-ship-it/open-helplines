# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and remember the people this project is for. Harassment, and deliberately adding false or harmful contact information, lead to a ban.

Report conduct issues to the repository owner, [mpatel-playground](https://github.com/mpatel-playground), by opening a private security advisory on this repository or contacting them via GitHub.
