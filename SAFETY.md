# Safety

This directory may be shown to people in crisis. We treat data errors as safety issues.

## If you need help right now

Call your local emergency number. If you're not sure what it is, the [web lookup](https://mpatel-playground.github.io/open-helplines/) shows it where we have it.

## Reporting a wrong or dead number

Use the [report form](https://github.com/mpatel-playground/open-helplines/issues/new?template=report-wrong-info.yml). Tell us the country, the entry, what's wrong, and how you know. Reports get the `urgent` label and go to the front of the queue.

If a number now reaches something harmful (for example, a scam line or an unrelated business), say so in the title. We remove first and investigate after.

## For apps and AI assistants using this data

- Show the local emergency number alongside helplines.
- Prefer `verified` entries, or show the `source` link for `provisional` ones.
- Cache with a short lifetime (a day or a week), so corrections reach your users.
- This is a directory. It doesn't replace your own safety design or clinical guidance.

## Security

Found a vulnerability in the tooling or site? Use GitHub's private vulnerability reporting on this repository rather than a public issue.
